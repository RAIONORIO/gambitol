# Gambitol

Gambitol é um jogo de xadrez para dispositivos Android desenvolvido em Java.

## Objetivo

Criar um jogo de xadrez mobile completo, com foco no estudo e aplicação prática de Java, desenvolvimento Android, orientação a objetos, regras de negócio, algoritmos e boas práticas de arquitetura.

O projeto será desenvolvido inicialmente para partidas locais entre dois jogadores no mesmo dispositivo.

## Plataforma

- Android
- Mobile

## Linguagem

- Java

## Primeira versão

A primeira versão do Gambitol deverá permitir:

- Exibição de um tabuleiro 8x8
- Seleção de peças por toque
- Movimentação das peças
- Alternância entre jogadores
- Captura de peças
- Validação dos movimentos
- Detecção de xeque
- Detecção de xeque-mate
- Detecção de empate
- Roque
- En passant
- Promoção de peão

## Evoluções futuras

Após a versão inicial, poderão ser adicionados:

- Cronômetro
- Histórico de jogadas
- Salvamento de partidas
- Inteligência artificial
- Diferentes níveis de dificuldade
- Multiplayer online
- Estatísticas
- Personalização do tabuleiro e peças

## Arquitetura

O motor de xadrez será desenvolvido separadamente da interface Android.

Isso permitirá manter as regras do jogo independentes da camada visual e facilitar testes, manutenção e futuras evoluções.

## Publicação

O objetivo final do projeto é publicar o Gambitol na Google Play Store.
